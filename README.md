# 髂胫束为什么会痛

一个 10 页的 3D 交互讲解页，用真实人体解剖模型说明髂胫束综合征（ITBS）的疼痛机制：疼的是谁、为什么在屈膝 20–30° 时被压、为什么臀中肌无力会让髂胫束更紧，以及怎么缓解。

在线查看：https://championwang00.github.io/itb-pain-3d/

## 功能

- 真实解剖网格，皮肤半透明，可拖动旋转、缩放
- 逐页讲解，正在讲的结构用描边高亮，关键点位用小圆点标注
- 鼠标指到任意结构或标签，对应部位会框出并显示名称
- 静止 / 跑步视角切换，跑步时右膝角度与压迫区实时联动
- 膝外侧压迫示意、骨盆跷跷板与对侧骨盆下沉动画

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件离线版（库和模型数据都已内嵌），可直接双击打开 |
| `髂胫束疼痛讲解.html` | 源码版，运行时从 `data/` 读取模型，Three.js 从 CDN 加载 |
| `data/anat.json`、`data/anat.b64.txt` | 截取并量化后的下半身解剖网格 |

## 数据来源与许可

解剖模型来自 [BodyParts3D](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/)，© The Database Center for Life Science，按 [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/) 授权。本仓库对其做了截取（下半身）、量化压缩和重新着色，`data/` 中的衍生数据同样按 CC BY-SA 2.1 Japan 发布。黄色脂肪垫为讲解用的示意物体，不来自原始数据。

跑步动作和骨盆下沉动画是程序近似生成的，不是动作捕捉数据，倾斜角度做了放大。
